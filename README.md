# WD-Activity-Based-Lear# Web Development Activity-Based Learning

## Project Description
This project contains three web development case studies created using HTML and CSS. These webpages demonstrate basic webpage structure, styling, navigation, and content presentation.

## Case Studies

### Case Study 1: My Portfolio
This webpage displays personal profile information, skills, education, and other details using HTML and CSS.

### Case Study 2: College Information
This webpage provides college-related information in a simple and organized format using HTML and CSS.

### Case Study 3: Online Food Ordering
This webpage demonstrates an online food ordering interface with food items, menu details, and ordering-related information.

## Technologies Used
- HTML
- CSS

## Objectives
- To learn basic HTML webpage structure.
- To apply CSS styling to webpages.
- To create simple and user-friendly webpages.
- To understand webpage navigation and content organization.

## Conclusion
This project helped me understand the fundamentals of web development using HTML and CSS and gain practical experience in creating simple webpages.
